# Attacker Exchange Complete Listing And Sorting

The Attacker Exchange tab now renders every command-bearing session and every matched command/response pair instead of limiting the view to eight sessions and five pairs per session. A client-side selector sorts sessions by newest exchange, command count, transcript length, duration, risk, behavior type, or remote endpoint. Transcript length counts command text and displayed response text.
